# Homiva Client

Homiva Client is a Next.js web application with a responsive authentication interface for login and registration.

## Overview

- Built with Next.js App Router and React
- Written in TypeScript
- Styled with Tailwind CSS
- Includes reusable authentication and UI components
- Provides login and registration pages

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn-style UI components and Lucide icons

## Project Setup

### Prerequisites

- Node.js 20 or newer
- npm

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd homiva-client
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — run the production build
- `npm run lint` — run ESLint
